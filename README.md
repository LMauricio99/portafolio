# Portafolio de Mauricio Lozada

Mi presentación personal y una selección de proyectos de desarrollo web. Incluye AnimeHaven y el encriptador de texto del programa ONE de Oracle y Alura, con acceso a las demos y al código.

Hecho con HTML, CSS y JavaScript, sin dependencias ni paso de compilación.

## Abrir localmente

```bash
python -m http.server 8766
```

Abre http://localhost:8766. `index.html` contiene el contenido, `styles.css` el diseño adaptable y `app.js` el estado de la navegación. Las imágenes muestran las demos reales de los proyectos.

El contacto se realiza mediante LinkedIn. No se recopilan datos ni se utilizan cookies de seguimiento.

Demo: https://lmauricio99.github.io/portafolio/
